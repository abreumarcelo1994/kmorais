Conectar Repositório do GitHub

Ao clicar em Publicar no GitHub, as edições são salvas diretamente no arquivo content.json do seu repositório oficial. Isso atualiza o site na internet para qualquer pessoa no mundo.

O token fica guardado em segurança apenas no seu navegador atual.

Como gerar seu token no GitHub (1 minuto):

Atenção: sua conta do GitHub precisa ter sido adicionada como Colaboradora no repositório.

  1. Acesse github.com/settings/tokens.
  2. Clique em Generate new token → Generate new token (classic).
  3. Em Note, digite KMORAIS CMS e marque a caixa repo.
  4. Clique em Generate token no final da página, copie o código ghp_... e cole aqui.
